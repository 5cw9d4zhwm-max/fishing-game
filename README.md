# 푸른 바다 낚시

브라우저에서 바로 열 수 있는 HTML 낚시 게임입니다. 별도 설치가 필요 없습니다.

## 실행 방법

1. `index.html` 파일을 더블클릭합니다.
2. 브라우저가 열리면 **낚시하기**를 눌러 게임을 시작합니다.
3. 잡은 물고기는 자동으로 판매되고, 전과 도감 기록은 브라우저에 자동 저장됩니다.

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 `fishing-game` 폴더 안의 `index.html`, `styles.css`, `app.js`, `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 대상을 `main` 브랜치의 `/(root)`로 선택하고 저장합니다.
4. 잠시 후 표시되는 주소를 열면 게임을 공유할 수 있습니다.

게임 진행도는 각 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 브라우저에서는 새 게임으로 시작합니다.
